# Part 3 — 헤더 영역 (장소 정보 + 우측 아이콘 버튼)

> 원본: `fixtheeverything.md` §헤더 영역, §우측 상단 아이콘 버튼

## 목표

핸들바 아래 장소 기본 정보(이름/주소/평점/카테고리/영업 상태)와 우측 원형 아이콘 버튼 3개를 Google Maps와 동일한 밀도로 구현.

## 할 일

### 1. 장소 이름

- fontSize 28px 내외, fontWeight 700, color `#1a1a1a`, lineHeight 34
- 최대 2줄, 긴 이름 자연스러운 줄바꿈
- Collapsed 상태에서는 22~24px로 축소 가능

### 2. 부제 / 주소

- fontSize 17px, color `#5F6368`, lineHeight 23, 최대 2줄

### 3. 평점 줄

예: `4.1 ★★★★★ (2,094) · 🚇 16시간 12분`

- fontSize 16px
- rating number `#5F6368`, star `#FBC02D`, review count `#5F6368`
- **이동시간 정보 없으면 표시 금지. mock 이동시간 금지**

### 4. 카테고리 / 가격대

예: `일본라면 전문식당 · ¥1,000~2,000`

- fontSize 16px, color `#5F6368`
- **값 없으면 해당 항목 표시 금지**

### 5. 영업 상태

예: `영업 중 · 오후 11:00에 영업 종료` / `영업 종료 · 오전 9:00에 영업 시작` / `24시간 영업`

- fontSize 16px
- open `#137333` / closed `#C62828` / 곧 닫음 `#B06000` 계열
- **placeDetails에 정보 없으면 렌더링 자체 금지**

### 6. 우측 상단 원형 아이콘 버튼 3개 (저장 / 공유 / 닫기)

```ts
width: 44, height: 44, borderRadius: 22
backgroundColor: '#F5F3F3'
gap: 12
```

- 아이콘 파일 없으면 임시 텍스트 아이콘: `♡`/`🔖`, `↗`/`⤴`, `×`
- png 파일 임의 생성 금지 → 필요 아이콘 목록은 Part 8 문서로 작성
