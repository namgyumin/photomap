# Part 6 — 전체화면 사진 뷰어

> 원본: `fixtheeverything.md` §전체화면 사진 뷰어

## 목표

사진 탭 시 Google Maps처럼 검은 배경 전체화면 뷰어 오픈.

## 할 일

### 1. 구성

```
┌──────────────────────────────────────┐
│  ×                              1 / 3 │
│                                      │
│              Photo                   │
│                                      │
│ ‹                                ›   │
└──────────────────────────────────────┘
```

### 2. 요구사항

- `Modal` 사용, `animationType="fade"`
- backgroundColor: black
- 사진: contain 또는 cover 중 자연스러운 방식
- 좌상단 닫기 버튼
- 우상단 `현재 index / 전체 개수`
- 좌우 화살표 내비게이션
  - 첫 사진: 왼쪽 화살표 opacity 0.3
  - 마지막 사진: 오른쪽 화살표 opacity 0.3
- swipe 가능하면 구현, 어렵다면 좌우 버튼이라도 **반드시** 구현
